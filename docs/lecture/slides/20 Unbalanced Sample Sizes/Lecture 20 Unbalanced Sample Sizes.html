Balanced Sample Sizes

In the examples we’ve been dealing with so far, our factorial ANOVAs have had balanced sample sizes

  • Sample \(n\) in every cell
table(dat$hill, dat$condition)
      
        a  b control
  east 50 50      50
  west 50 50      50

This is desirable when possible

  • Maximizes statistical power
  • Makes factors orthogonal
    • There aren’t more or less cases in a given condition for the east rather than west side of the hill

Not always possible!

Unequal Sample Sizes

In this dataset, not all groups have equal sample sizes:

table(exline$gender, exline$condition)
        
         capability first vengefulness first
  male                 31                 24
  female               33                 47

The research design problem:

  • Missing data (dropout, unusable responses)
  • Pre-existing groups may be hard to sample in equal proportions

The Statistical Problem

  • If sample sizes in ANOVA are unequal, then effects are correlated
  • For male, \(n_{\text{capability first}} > n_{\text{vengefulness first}}\)
  • For female, \(n_{\text{capability first}} < n_{\text{vengefulness first}}\)

Why might this be a problem?

  • How will this affect the marginal effect of gender?
  • Will the condition order maybe have an unintended impact on the marginal means of gender?
    • Because there are more males who saw capability first, the marginal mean of male is going to be weighted more towards capability first
    • Because there are more females who saw vengefulness first, the marginal mean of female is going to be weighted more towards vengefulness first
      • Effects of gender and condition are confounded

Similarities\Differences

  • The results for the interaction are always the same
  • The types of SS are different ways of accounting for the main effects
  • Type I includes the confounding effect for whichever factor is entered first
  • Removes confounding factor for factor entered second
    • Only sensible if you think the population is also unbalanced AND care about that imbalance on the first factor in the model
  • Type II assumes main effects are unconfounded by interaction
    • Most useful if you are OK assuming a negligible interaction in the population
    • If so, more powerful test of main effect
  • Type III assumes main effects are confounded byt interaction
    • Most useful if you are assuming a non-negligible interaction in the population
    • Main effect tests less powerful, but also main effects have less clear interpretation if interaction is present, so may not be an issue

Recommendations I

When data are balanced, all three give the same results

When data are unbalanced:

  • Type I is rarely appropriate
    • Accounts for variables in a particular order
    • Only consider if you believe population is unbalanced and want to let that imblanace influence your results
      • E.g. can be appropriate in demography when groups do naturally differ in frequency
      • Never appropriate in randomized experiments
    • Default SS if using aov()

Recommendations II & III

When data are balanced, all three give the same results

When data are unbalanced:

Type II

  • More powerful than type III if you believe the interaction is negligible in the population
    • Sometimes interpreted as “interaction is non-significant”
  • Default SS if using ezANOVA

Type III

  • Recommended if interaction effect is non-negligible
  • Default in SPSS which made this approach popular/conventional

Types in R

The way R is programmed, Type II is straightforward. However, Type III is not always

  • Some packages cannot get Type III if the model uses dummy coding as contrast
  • Requires contrasts to be orthogonal
    • Sum to zero
    • Sum of products of pairs of contrast columns must sum to zero
  • Dummy coding does not sum to zero, despite being default in R and most common contrast scheme
  • Effects coding is a viable alternative

Exline Type III car

For Type II and III we can use car::Anova() or ez::ezANOVA(). For Type III using car::Anova(), we must set orthogonal (e.g. effects coded) contrasts before using aov() or the results will be incorrect. We can do this globally for all factors by first specifying options(contrasts = c(unordered = "contr.sum", ordered = "contr.poly"))

  • contr.sum is effects cody
  • contr.poly is orthogonal polynomial contrasts for ordinal factors (not covered)

Output Differences

Note that the interaction never changes. Only the main effects results differ for the different types. In this case, the main effects barely even changed! Why?

  • Hint: Does the ges column (\(\eta^2\)) in the ezANOVA() output indicate a small or large interaction effect?
  • It’s a very small interaction effect, so even if we use Type II, The interaction can’t really impact the main effects

APA Writeup

The interaction effect is not statistically significant (\(F(1, 131) = .02, p = .89\)). There is a significant main effect of gender (\(F(1, 131) = 4.51\), \(p = .04\)), but no main effect of condition (\(F(1, 131) = .08, p = .77\)). Males have higher vengefulness scores than females (Cohen’s \(d\) = .39).

Note from Mark (note part of APA writeup): Post-hoc tests are not necessary for the effect of gender because this variable has only two levels. Means we don’t need additional tests and can just calculate \(d\) for difference between males and females
