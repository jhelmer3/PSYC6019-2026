Categorical Predictors

So far, we have discussed regression with continuous predictors

It is also possible to use categorical predictors in regression models, or both categorical and continuous predictors

A regression model with only categorical predictors is identical to a technique we have already learned. What is it?

  • criterion: performance (math) IQ—continuous

  • predictor 1: verbal IQ—continuous

  • predictor 2: sex (female, male)—categorical

Dummy Coding Review

For \(k\) groups, we can represent group membership with (\(k-1\)) dichotomous dummy variables

For each dummy variable, assign ‘1’ to members of one group and ‘0’ to all others

One group (called the reference group) is coded ‘0’ on all dummy variables

Example:

Group \(x_{1}\) \(x_{2}\) \(x_{3}\)
Control 0 0 0
Drug 1 0 0
Therapy 0 1 0
Drug + Therapy 0 0 1

Dummy Coded Model

Regression model:

\[\hat{y} = b_0 + b_1x_1 + b_2x_2 + b_3x_3\]

  • Control: \(\hat{y} = b_0\)

  • Drug: \(\hat{y} = b_0 + b_1x_1\)

  • Therapy: \(\hat{y} = b_0 + b_2x_2\)

  • D + T: \(\hat{y} = b_0 + b_3x_3\)

Group \(x_{1}\) \(x_{2}\) \(x_{3}\)
Control 0 0 0
Drug 1 0 0
Therapy 0 1 0
Drug + Therapy 0 0 1

Interpretation:

  • \(b_0\): predicted \(\hat{y}\) for control group
  • \(b_1\): difference in \(\hat{y}\) between (drug) and (control)
  • \(b_2\): difference in \(\hat{y}\) between (therapy) and (control)
  • \(b_3\): difference in \(\hat{y}\) between (drug + therapy) and (control)

Dummy Coded Tests

Test of individual predictors:

  • If \(b_1\) is significant, then the \(x_1\) group (drug group) differs significantly from the control group (contrast coding, excluding other groups)

  • Degrees of freedom for the one-way ANOVA ( = #groups - 1) are divided into (#groups - 1) contrasts comparing each group to the reference group

Test of \(R^2\)

  • Equivalent to the omnibus test for the one-way ANOVA!

  • Test the hypothesis that all coefficients are simultaneously zero

Effects Coding Review

As with dummy variables, for \(k\) groups, we need \(k-1\) effect variables

Each effect code consists of ‘1’ for members of one group, ‘-1’ for members of another group, and ‘0’ for the remaining groups

The same group receives the ‘-1’ effect for each effect variables

For example:

Group \(x_{1}\) \(x_{2}\) \(x_{3}\)
Control -1 -1 -1
Drug 1 0 0
Therapy 0 1 0
Drug + Therapy 0 0 1

Effects Coded Model

Regression model:

\[\hat{y} = b_0 + b_1x_1 + b_2x_2 + b_3x_3\]

Interpretation:

  • \(b_0\): grand mean of \(y\)

  • \(b_1\): difference in \(\hat{y}\) between drug and grand mean

  • \(b_2\): difference in \(\hat{y}\) between therapy and grand mean

  • \(b_3\): difference in \(\hat{y}\) between (drug + therapy) and grand mean

Omnibus test of \(R^2\) is equivalent to simultaneously testing main effects in ANOVA

ANOVA interaction corresponds to moderation effects—stay tuned!

Consequences

Multicollinearity is the extent to which predictors are correlated with other predictors in a regression model

Consequences of severe (high) multicollinearity:

  1. Partial regression coefficients have large standard errors

    • Consider:

    \[s_{b_1} = \frac{s_y}{s_{x_1}}\sqrt{\frac{1-R^2}{(N-p-1){\color{#377EB8}\boxed{(1-r_{x_1,x_2}^2)}}}} \qquad {\color{#377EB8}\begin{array}{l}\text{When } r_{x_1,x_2} \text{ is large,} \\ s_{b_1} \text{ is large}\end{array}}\]

    • Low statistical power of partial regression coefficients

  2. In extreme cases, results cannot be calculated (no unique solution to the OLS equations)

    • This will always occur if \(p > N - 1\), and sometimes with fewer predictors

Variance Inflation Factor

Two collinearity statistics:

  • Variance Inflation Factor (VIF)

  • Tolerance = 1 / VIF

  • Just different ways of framing the same statistic

VIF for \(x_j = \frac{1}{1 - R^2_j}\)

  • \(R^2_j\), \(j = 1, \ldots, p\) is the \(R^2\) value from the regression of \(x_j\) (treating \(x_j\) as the DV) on all other predictors in the regression model

If the model we care about is

\[y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_3 + \epsilon\]

Then \(R^2_1\) is the \(R^2\) for this model:

\[x_1 = \beta_{(1),0} + \beta_{(1),1} x_2 + \beta_{(1),2}x_3 + \epsilon_{(1)}\]

VIF And Tolerance

  • VIF is how much the standard error increases due to multicolinearity for that predictor

    • Example: VIF = 1.057 means that our estimate for \(s_{b_1}\) is 1.057 times as large as it would be if \(x_1\) were uncorrelated with the other predictors (\(R^2_1 = 0\))

  • Tolerance is the inverse of VIF: proportion of variance of \(x_j\) that is independent of other predictors

Rules of thumb:

  • VIF > 5 (tolerance < .2) indicates high multicollinearity
  • VIF > 10 (tolerance < .1) indicates serious multicollinearity

Assumptions

  1. Fixed effects model

  2. Conditional distributions are normally distributed with constant variance (homoscedasticity)

  3. Independent and normally distributed residuals

  4. Correct model specification

  5. Perfectly reliable predictors

  6. No multivariate outliers

Model Usage Review

What are the three things we typically use models for? (Way back in lecture 12!)

Assumption Impacts

Assumptions (esp. 1 and 2) are the necessary conditions for hypothesis tests to have known properties (e.g., Type I error rate)

  • Biggest impact on our decision rules for frequentist inference

  • A bit less relevant when regression is used for description

  • Can be relevant for prediction and non-frequentist decision-making

  • All of these can affect results, so they are important to be aware and understand consequences of

Fixed Effects Model

The multiple regression model treats predictors as fixed

  • Interest is in specific predictors
  • Predictors are systematically included in the sample and would be included in all sample replications
  • e.g., attractiveness ratings on a specific photograph (rather than a randomly sampled photograph)

In contrast, random effects models

  • Predictors are sampled from a distribution

  • Examples:

    • Attractiveness ratings on one of many photographs that could have been used
    • Time points in repeated-measures design

  • Can be accommodated with multilevel regression models

Conditional Distributions

In fixed effects regression, we assume that predictors are fixed constants

For every combination of predictors, we have a distribution of \(y\)

  • “Conditional distribution of \(y\)”

Assume that each conditional distribution

  • Is normally distributed

  • Has constant variance

  • Known as homoscedasticity

    • Extension of homogeneity of variance for all values of a continuous predictor rather than discrete groups

Conditional Distributions

What if normality is violated?

  • Nonnormality does not bias estimated regression coefficients
  • Nonnormality can increase standard errors of regression coefficients
  • For small samples, \(t\) tests (for regression coefficients) and \(F\) test (for \(R^2\)) may be biased
  • For moderate to large samples, effects of nonnormality on significance testing is small

What if homoscedasticity is violated?

  • Heteroscedasticity does not bias estimated regression coefficients
  • Heteroscedasticity does bias standard errors of regression coefficients
  • Direction of bias depends on the relationship of the conditional variances to the predictor
    • If variance increases as predictor increases, standard error is underestimated and Type I error rates are inflated
    • If variance decreases as predictor increases, standard error is overestimated and Type I error rates are too low

Residuals

We also assume that all residuals are independent of each other

If observations are random, then residuals shouldn’t be correlated

In some situations, residuals might be correlated. Examples:

  • Observations from the same person at different times

    • Observations closer in time may be more related than those farther in time
    • Known as temporal autocorrelation
    • Repeated measures nested within individuals

  • Observations from individuals in the same community

    • Observations from people who are geographically closer together may be more related than those from those from diverse geographic locations
    • Known as spatial autocorrelation
    • Individuals nested within communities

Multilevel modeling is a better method to handle these types of data

Residuals

What are the consequences of autocorrelation among residuals across observations?

  • Autocorrelation does not bias estimated regression coefficients

    • However, multilevel models can also help understand effects single level models cannot when there is autocorrelation

  • Standard errors of regression coefficients can be underestimated, leading to inflated Type I error rates for \(t\) tests of regression coefficients

  • Can inflate Type I error rate of \(F\) test for \(R^2\)

Model Specification

  • Scatterplots of residuals (\(y\)-axis) against predicted outcome values (\(x\)-axis) with loess line imposed

  • Scatterplots of residuals (\(y\)-axis) against each predictor (\(x\)-axis) separately, with loess lines imposed

  • If forms of relationships are properly specified, then loess lines should not exhibit large or systematic deviations from the \(y=0\) horizontal line

Additivity

  • Regression coefficient: relationship of one predictor to the outcome, when all other predictors are held constant (i.e., partialing out other predictors)

  • We do not indicate at what specific value each variable is held constant

  • Rather, the partial relationships should be constant regardless of the values of the other variables that are being held constant

  • This is called additivity, that the relationship of one predictor to the outcome does not depend on specific values of the other variables

  • Example of non-additivity: moderation (interaction, coming soon!):

\[\hat{y} = b_0 + b_1x_1 + b_2x_2 + b_3 (x_1 \times x_2)\]

  • Regression slope of \(y\) on \(x_1\) depends on the value of \(x_2\)

  • Define a new variable (\(x_1 \times x_2\)) and enter into the regression model that is linear in coefficients

CTT

Regression (and the other methods we’ve learned so far) assume that the variables are perfectly reliable

The concept of reliability is based on classical test theory (CTT):

\[X = T + e\]

  • \(X\): Observed score
  • \(T\): True score (perfectly reliable)
  • \(e\): Random measurement error

Reliability

Quantifies proportion of observed score attributable to true score

  • Put another way: how free from measurement error is observed score?

\[\text{Reliability } = \sigma^2_T / \sigma^2_X\]

  • \(\sigma^2_X\): variance of observed \(X\) scores
  • \(\sigma^2_T\): variance of true scores

Reliability ranges from 0 to 1 (perfectly reliable)

Perfectly Reliability

Unreliable predictors bias regression coefficients

The direction of bias is not always predictable in advance

Single predictor:

  • If the predictor is unreliable, its regression coefficient will be closer to zero than in the population

  • Underestimated effect size and low statistical power

  • Correlations involving an unreliable variable are lower than if the variable is perfectly reliable

Multiple predictors

  • Typical, but not necessary, that regression coefficients will be closer to zero

Methods such as structural equation modeling often better accommodate variables that are not perfectly reliable

Multivariate Outliers

We have an intuition as to what constitutes univariate outliers

  • A 4’10” adult human

  • A 400lb adult human

It is also possible to have multivariate outliers - values that are not necessarily unusual for individual variables, but whose combination is unusual

  • An adult human who is 6’2” and 120 lbs

Regression Diagnostics

Multiple regression is not robust to:

  • Stray data points that fall far from the swarm of points in the predictor space
  • Outcome \(y\) values that are unusual, given values of the predictors

These errant points are called outliers

  • They may have no effect on the regression analysis results
  • They may drastically affect the regression analysis results

Three characteristics of data points:

  1. Leverage: extent to which observation is close to or far from the rest of other observations, in terms of scores on the predictors only
  2. Distance: extent to which the observation’s score on the outcome is extreme, given the values on the set of predictors
  3. Influence: extent to which a single data point changes the outcome of the regression analysis

Leverage

  • Leverage does not consider any information about the outcome

  • Leverage reflects the distance of an observation from the centroid of the predictor space

  • Leverage reflects the potential of the observation to affect the regression results

Leverage statistic \(h\) (or “hat”):

  • Measure of how far each observation is from the centroid of the predictors

  • Think: a \(p\)-dimensional scatterplot - how far is each observation from the center of mass?

  • Leverage values range from \(1/N\) to 1

  • Take a closer look at leverage values > \(3(p+1) / N\)

Distance

High distance reflects unusual \(y\) scores, given predictor scores

Measures of distance are based on the residuals

Distance measures (for each observation):

  • Raw/unstandardized residuals (\(y - \hat{y}\))

    • Not very informative because no suggested cutoff recommended
    • No general cutoff because residuals are in the units of \(y\)
    • Not suggested

Standardized Distance

Two Types:

  • Internally studentized residuals

\[\frac{y - \hat{y}}{\sqrt{MS_{\text{residual}}\times (1 - h)}}\]

  • Externally studentized residuals

\[\frac{y - \hat{y}}{\sqrt{MS_{\text{residual}(i)}\times (1 - h)}}\]

Internal Studentization

\[\frac{y - \hat{y}}{\sqrt{MS_{\text{residual}}\times (1 - h)}}\]

\(h\): leverage values

\(MS_{\text{residual}}\) is the squared residual standard error

  • Numerator (\(y - \hat{y}\)) and denominator (\(MS_\text{residual}\)) are not independent
  • If observation greatly affects regression, \(MS_\text{residual}\) will be affected
  • Not recommended

External Studentization

\[\frac{y - \hat{y}}{\sqrt{MS_{\text{residual}(i)}\times (1 - h)}}\]

\(h\): leverage values

\(MS_{\text{residual}}\) is the squared residual standard error

  • \(MS_{\text{residual}(i)} = MS_{\text{residual}}\) using dataset without target observation \(i\)
  • Independent numerator and denominator
  • Suggested cutoff: if > 2.5 in absolute value, outstanding distance
  • Recommended distance measure

Influence

An observation might have high leverage or high distance and still not affect the position of the regression plane

Influence is the extent to which an observation actually changes the regression results

Influence is a function of both leverage and distance

Influence measures:

  • DFFITS

  • DFBETA

  • Cook’s distance

  • COVRATIO

DFFITS

Influence measures (for each observation):

DFFITS: global measure of standardized change in predicted scores

\[\text{DFFITS} = \frac{\hat{y} - \hat{y}_{(i)}}{s_{\hat{y}_{(i)}}}\]

  • \(\hat{y}\): predicted outcome for observation \(i\) when observation \(i\) is included in the regression
  • \(\hat{y}_{(i)}\): predicted outcome for observation \(i\) when observation \(i\) is excluded from the regression (use fitted model to predict the outcome)
  • \(s_{\hat{y}_{(i)}}\) standard error of \(\hat{y}_{(i)}\)
  • DFFITS reflects how much the regression line changes if observation \(i\) is deleted
  • Suggested cutoffs:
    • Moderate \(N\): absolute DFFITS > 1, outstanding influence
    • Large \(N\): absolute DFFITS > \(2\sqrt{(p+1)/N}\), outstanding influence

DFFITS Viz

DFBETAS

Influence measures (for each observation):

DFBETAS: measures the standardized change in regression coefficients

\[\text{DFBETAS} = \frac{b - b_{(i)}}{s_{b_{(i)}}}\]

  • \(b\): regression coefficient when observation \(i\) is included in the regression

  • \(b_{(i)}\): regression coefficient when observation \(i\) is excluded from the regression

  • \(s_{b_{(i)}}\) standard error of \(b_{(i)}\)

Suggested cutoffs:

  • Moderate sample size: absolute DFBETAS > 1, outstanding influence

  • Large sample size: absolute DFBETAS > \(2/\sqrt{N}\), outstanding influence

DFBETAS viz

Others

Influence measures (for each observation):

  • Cook’s Distance: Global measure of influence

    • Closely related to DFFITS, but with squared differences

    • Suggested cutoff: \(D > 1\) indicates influential point

  • COVRATIO

    • Global measure of influence based on sizes of standard error of each regression coefficient when observation \(i\) is included/excluded from regression analysis

    • Smaller covratio, more stable regression coefficients (smaller standard errors)

    • Suggested cutoff: |covratio - 1|\(\geq 3p/N\) indicates less stable regression coefficients

Influence

Summary

Diagnostics usually consider one observation at a time

Some suggested strategies:

  • Look at global influence DFFITS first. Look for observations with DFFITS > \(2 \sqrt{(p+1)/N}\)

  • For these observations, look at all the DFBETAS. Be concerned if DFBETAS > 1

  • Examine these observations for data entry errors (or other errors unrelated to the study)

  • Unless a strong case can be made for deleting the observation, the observation stays
