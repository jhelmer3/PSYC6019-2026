\(t\) Revisited

If we want to compare treatment1 to control in a \(t\)-test, we have the following formula

\[t = \frac{\bar{x}_{\text{treatment1}}- \bar{x}_{\text{control}}}{\sigma_{\bar{x}_{\text{treatment1}}- \bar{x}_{\text{control}}}}\]

My question: how will I define \(\sigma_{\bar{x}_{\text{treatment1}}- \bar{x}_{\text{control}}}\)?

I’ll give you two options

  • Pooled standard error for treatment and control groups

  • Use \(\sqrt{\text{MSW}}\) for something

Which do you want to use?

Discussion

Why did \(\sqrt{\text{MSW}}\) provide a better estimate (on average) of the population pooled standard deviation than the sample pooled standard deviation for \(x_1\) and \(x_2\)?

  • Does \(x_3\) have a different standard deviation than \(x_1\) or \(x_2\)?
  • Because we assumed homogeneity of variance we want to use all of our data to estimate the common standard deviation
  • Even if our specific comparison omits a group, that group provides more data to estimate the shared variance
  • And \(\text{MSW}\) IS an estimate of the shared, within group variance! (all groups)

Using MSW in \(t\)

Modified \(t\) test statistic:

\[t(df) = \frac{\bar{x}_1 - \bar{x}_2}{s_{\bar{x}_1 - \bar{x}_2}}\]

where

\[s_{\bar{x}_1 - \bar{x}_2} = \sqrt{\frac{MSW}{n_1} + \frac{MSW}{n_2}}\]

  • \(df = dfW\)
  • \(n_1, n_2\): sample sizes for groups 1 and 2

Multiple Comparisons

What if we want to make more than one comparison?

Family-Wise Error (FWE) Rate

  • The probability of rejecting at least one true \(H_0\) in a series of comparisons.
  • The probability of committing at least one Type I error in a series of comparisons.

xkcd Significant Comic

  • If no jelly bean color causes acne, there is a high probability that we will reject \(H_0\) for at least one test.

  • To avoid high FWE, we test all the hypotheses at the same time with an omnibus test.

  • But what if we WANT to test the hypotheses individually?

Multiple Comparisons

So far, we have only learned about the omnibus test against the null hypothesis:

  • Are all group means equal in the population?

Or the test of a single comparison

  • Does one specific group differ from another

Often, we want to also know whether differences occur among all pairs of groups.

Running multiple tests on the same data leads to an inflated Type I error rate. If all of the tests are independent:

[ ^= 1 - (1 - )^k ]

  • \(k\): number of comparisons made or tests done
  • \(\alpha\): specified Type I error rate
  • \(\alpha^\star\): actual Type I error rate (probability of rejecting at least one correct null)

For a study with \(G\) groups, there are \(k = \frac{G(G-1)}{2}\) pairs of groups. That means we would do \(k\) different tests if we want to compare each individual group to each other group.

Logic of Error Inflation I

Recall, for two independent events:

\[P(A \cap B) = P(A)P(B)\]

  • In this case, the independent events are the probability of correctly retaining the null. Since the probability of incorrectly rejecting is \(\alpha\), the probability of correctly retaining is \(1 - \alpha\).

  • If we have \(k\) independent tests, then the probability of correctly retaining the null for every single test jointly is:

Logic of Error Inflation II

\[P(\text{retain}_1 \cap \text{retain}_2 \cap \text{retain}_3 \cap \dots \cap \text{retain}_k) =\] \[P(\text{retain}_1) \times P(\text{retain}_2) \times \dots \times P(\text{retain}_k) =\] \[(1-\alpha)_1 \times (1-\alpha)_2 \times \dots \times (1-\alpha)_k =\] \[(1-\alpha)^k\]

That means that the probability that we incorrectly reject at least one of those null hypotheses is:

\[1 - (1 - \alpha)^k\]

Inflated Type I Errors for Jellybeans

xkcd Significant

In the jellybean comic, we aren’t comparing groups to one another, but we do have \(k = 20\) different tests.

  • Actual Type I error rate \(\alpha^\star = 1 - (1 - .05)^{20} = \mathbf{.64}\) !!!

Interpretation: There is a 64% chance we would reject the null hypothesis for at least one jellybean color just by chance even if all null hypotheses were true*.

* And if all of the tests were independent

Multiple Comparisons

Traditional Procedures:

  • When ANOVA is not significant, we DO NOT conduct multiple comparisons of mean differences between pairs of groups.
  • When ANOVA is significant, we might conduct multiple comparisons to examine which pairs of groups contribute to the significant results.

Modern Recommendations:

  • Conduct multiple comparisons regardless of the significance of the simple ANOVA test.
  • Multiple comparisons do not require a significant omnibus test.
  • Multiple comparison procedures control the Type I error rate of each comparison.

Post-Hoc vs. A Priori Comparisons

Post-hoc comparisons:

  • Mean comparisons between all pairs of groups after data collection.
  • Requires extra statistical control for Type I error rates.

A priori comparisons:

  • Mean comparisons based on planned hypotheses (before data collection).
  • Planned hypotheses are made before knowing ANOVA test results.
  • Usually fewer comparisons.
    • Higher power than all pairwise comparisons.

Bonferroni and Holm

Bonferroni Correction:

\[\text{adjusted } \alpha = \alpha / k\]

Holm Correction:

  1. Sort \(p\)-values from low to high.
  2. Compare to adjusted \(\alpha = \frac{\alpha}{k}, \frac{\alpha}{k-1}, \cdots, \frac{\alpha}{2}, \frac{\alpha}{1}\)
  • \(\alpha\): desired Type I error rate (e.g., .05) | \(k\): number of comparisons
  • If \(p < \text{adjusted } \alpha\): reject \(H_0\) for that pair
  • Holm’s adjustment is more powerful than Bonferroni’s

Tukey’s HSD I

Tukey’s Honestly Significant Difference (HSD) is a slightly different approach. Null and alternative hypotheses are the same as other pairwise comparisons.

Test statistic:

\[q(df, G) = \frac{\bar{x}_1 - \bar{x}_2}{s_{\bar{x}_1 - \bar{x}_2}}\]

where

\[s_{\bar{x}_1 - \bar{x}_2} = \sqrt{\frac{\left(\frac{MSW}{n_1} + \frac{MSW}{n_2}\right)}{2}}\]

  • \(MSW\): mean of within-group effect (from ANOVA table)
  • \(df = dfW\)
  • \(q\) follows a studentized range distribution (ptukey / qtukey in R)

Tukey’s HSD II

\((1 - \alpha)\%\) confidence intervals for \((\mu_1 - \mu_2)\):

\[(\bar{x}_1 - \bar{x}_2) \pm q(df)_{\alpha_{\text{adj}}/2} \times s_{\bar{x}_1 - \bar{x}_2}\]

  • \(df = dfW = N - G\)
  • \(s_{\bar{x}_1 - \bar{x}_2}\): standard error of \((\bar{x}_1 - \bar{x}_2)\)
  • \(\alpha_{\text{adj}}\): \(\alpha\) adjusted with either Bonferroni or Holm
  • \(q(df)_{\alpha_{\text{adj}}/2}\): \((\alpha_{\text{adj}}/2)^{\text{th}}\) quantile of the studentized range distribution with \(df\) degrees of freedom

Tukey’s HSD is more powerful than Bonferroni.

Games-Howell

Same \(H_0\) and \(H_1\) as Bonferroni/Holm/Tukey.

Test statistic:

\[q(df, G) = \frac{\bar{x}_1 - \bar{x}_2}{s_{\bar{x}_1 - \bar{x}_2}}\]

where

\[s_{\bar{x}_1 - \bar{x}_2} = \sqrt{\frac{\left(\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}\right)}{2}}\]

  • \(s_1^2, s_2^2\): sample variances of groups 1 and 2
  • \(n_1, n_2\): sample sizes of groups 1 and 2
  • \(q\) follows the Tukey distribution with \(df = dfW\) and \(G\) groups

Dunnett C and Dunnett T3

  • Neither procedure assumes homogeneity of variance
  • Both procedures successfully correct the Type I error rate for multiple comparisons
  • Comparisons among the 3 procedures:
    • Games-Howell performs better than Dunnett C and Dunnett T3
    • Dunnett C has higher statistical power than Dunnett T3 when \(dfW > 75\) (Tabachnick & Fidell, 2001)

Recommendations

Recommended post-hoc procedures:

  • Homogeneity of variance: Tukey HSD
  • Heterogeneity of variance: Games-Howell
  • Work with the same assumptions for both the ANOVA itself and for post-hoc tests

A Priori Comparisons

So far, we have learned about post-hoc tests (exploratory, look at all possible pairs).

A priori comparisons:

  • Comparisons planned before data collection
  • Guided by theory
  • Only some group differences may truly be of interest
  • Usually fewer comparisons
  • More statistically powerful

Linear Contrasts I

Example (4 groups): \(H_1\): \(\mu_1\) is different than the average of \(\mu_2\), \(\mu_3\), and \(\mu_4\)

Rewrite \(H_0\) and \(H_1\):

\[\begin{align*} H_0: & \quad 1\mu_1 + -\frac{1}{3}\mu_2 + -\frac{1}{3}\mu_3 + -\frac{1}{3}\mu_4 = 0 \\ H_1: & \quad 1\mu_1 + -\frac{1}{3}\mu_2 + -\frac{1}{3}\mu_3 + -\frac{1}{3}\mu_4 \neq 0 \end{align*}\]

Based on these hypotheses, we can define a linear contrast (\(\psi\)):

\[\psi = a_1 \bar{x}_1 + a_2 \bar{x}_2 + a_3 \bar{x}_3 + a_4 \bar{x}_4 = \sum a_g \bar{x}_g\]

  • Require \(\sum a_g = 0\)

Linear Contrasts II

What would be a linear contrast to compare \(\bar{x}_1\) to \(\bar{x}_2\)?

\[\begin{align*} H_0: & \quad 1\mu_1 + -1\mu_2 + 0\mu_3 + 0\mu_4 = 0 \\ H_1: & \quad 1\mu_1 + -1\mu_2 + 0\mu_3 + 0\mu_4 \neq 0 \end{align*}\]

Linear Contrasts III

For hypothesis testing:

\[t(df) = \frac{\psi}{s_\psi}\]

  • \(\psi\): linear contrast \(= \sum a_g \bar{x}_g\)
  • \(s_\psi\): standard error of contrast
  • Test statistic follows a \(t\) distribution with \(dfW\) degrees of freedom
  • Assumes homogeneity of variance

Linear Contrasts IV

Confidence interval:

\[\psi + t(df)_{\alpha/2}\times s_\psi\]

Effect size of linear contrast: Cohen’s \(d\)

\[d = \frac{\psi}{s}\]

Options for \(s\):

  • Sample SD of focal group of interest
  • \(\sqrt{MSW}\) (square root of mean squares within)

Specifying Weights

In our example, we use the following weights:

\[a_1 = 1, \quad a_2 = -\frac{1}{3}, \quad a_3 = -\frac{1}{3}, \quad a_4 = -\frac{1}{3}\]

The following weights will give the same results:

\[a_1 = 3, \quad a_2 = -1, \quad a_3 = -1, \quad a_4 = -1\]

Interpretation of contrast weights:

  • Group with positive weights will be compared to those with negative weights
  • Groups with zero weight are not considered in the contrast

Orthogonal Contrasts

Historically, researchers have conducted orthogonal contrasts:

  • \(G-1\) linear contrasts
  • For each contrast, \(\sum a_g = 0\)
  • For all pairs of contrasts (weights \(a_g\) and \(b_g\)), \(\sum (a_g b_g) = 0\)

Modern practices generally don’t require orthogonal contrasts:

  • Theory should drive comparisons
  • Orthogonality not required

Correct for multiple comparisons when specified a priori?

  • Traditional/textbook: Bonferroni, Holm, or other correction of \(\alpha\)
  • Modern: Open debate about whether correction is necessary

Trend Analysis

Special application of linear contrasts where groups are ordered (e.g., dosage levels 0ml, 5ml, 10ml, 15ml, 20ml).

More interested in the form of the relationship:

  • Linear relationship: (-2, -1, 0, 1, 2)
  • Quadratic relationship: (-2, 1, 2, 1, -2)
  • Cubic relationship: (-1, 2, 0, -2, 1)

The Bayesian Perspective

Do we need multiple comparisons adjustments when we use Bayesian methods? Why or why not?

  • Multiple adjustments are about adjusting the probability we make an incorrect decision based on a prescribed cutoff
  • If we use Bayes factors with a cutoff we might need something similar
  • Alternatively, we can just consider the posterior distribution
  • What range of effects are plausible based on posterior?

Posterior Extraction

  • Step 1: Set up linear model \(y_{ig} = \color{#377EB8}{\beta_0} + \color{#4DAF4A}{\sum_{p=1}^{g-1}\beta_p x_{p}} + \color{#984EA3}{\epsilon_i}\)
  • Step 2: Plug in for \(x\)’s to get \(\hat{y}\) for first (reference) group
    • If using dummy coding, this would be all \(x_p = 0\)
  • Step 3: plug in for \(x\)’s to get \(\hat{y}\) for group 2
    • If using dummy coding, this would be all \(x_1 = 1\) and all other \(x_2 \dots x_p = 0\)
  • Repeat for all groups
  • Do this across all draws from MCMC output
  • Calculate pairwise differences (or linear contrasts) for every draw

A one-way Bayesian ANOVA of social cues on affect evaluation was conducted. Pairwise comparisons between all groups were estimated. The contrast between the Close and Intermediate had a posterior mean \(= 0.13, 95\% \text{CI} = [-0.33, 0.56]\).
