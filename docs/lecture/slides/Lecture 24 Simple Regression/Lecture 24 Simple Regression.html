Regression Line

Last time, we saw that we can help summarize a scatterplot with a regression line

What is It?

  • Best fitting “straight” line
  • What is a line?
    • Has slope and intercept
      • $y = mx + b
    • Intercept: Value of \(y\) when \(x = 0\)
    • Slope: For one unit increase in \(x\), how many units increase in \(y\)?
    • How do we find this line?
    • What does “best fitting” mean?

Regression Vocabulary

  1. Criterion: The variable we are trying to predict, which is on the \(y\)-axis (usually the DV)
  2. Predictor: The variable used to predict the criterion, which is on the \(x\)-axis (usually the IV)
  3. Slope: The steepness of the line
  4. Intercept: The predicted value of the criterion when the predictor is at 0

Regression Equation

The form of the simple linear regression model is as follows:

Population Sample
\(y_{i} \mid x_{i} = b_{0} + b_{1}x_{i} + e_{i}\) \(y_{i} \mid x_{i} = \hat{b}_{0} + \hat{b}_{1}x_{i} + e_{i}\)
\(\hat{y}_{i} = b_{0} + b_{1}x_{i}\) \(\hat{y}_{i} = \hat{b}_{0} + \hat{b}_{1}x_{i}\)
  1. \(y_i \mid x_i\): The conditional mean value of \(y_i\) given a fixed/specific value of \(x_i\)
  2. \(\hat{y}_i\): Estimated outcome (\(\hat{\,\,\,}\): an estimated value)
  3. \(b_0\) (\(\hat{b}_0\)): The (estimated) intercept (predicted value of \(y_i\) when \(x_i = 0\))
  4. \(b_1\) (\(\hat{b}_1\)): The (estimated) slope (predicted increase in \(y_i\) for a one-unit increase in \(x_i\))
  5. \(e_i = y - \hat{y}\):
    • The residual or error when predicting \(y_i\) from \(x_i\)
    • The difference between a particular point and the regression line

  • For all cases where \(x = 0.50\), our estimated mean of \(\bar{y} | (x = 0.50) = 12.00\)

      • In fact, this what we are saying the SD of \(y\) is for any value of \(x\), \(\sy |x= \color{#984EA3} s_{\epsilon} = 3.27\)
  • For any given \(x\), the regression line tells us the expected mean of \(y\), with constant SD

Normal Equations

The best-fit line follows the form:

\[\hat{y}_i = \hat{b}_0 + \hat{b}_1 x_i\]

The estimated regression coefficients (\(\hat{b}_0\) and \(\hat{b}_1\)) are functions of familiar descriptive statistics:

\[\hat{b}_1 = \frac{s_{xy}}{s^2_{x}}\]

\[\hat{b}_0 = \bar{y} - \hat{b}_1 \bar{x}\]

These are known as the normal equations

Ordinary Least Squares

Where do these “normal equations” come from?

Method of ordinary least squares (OLS):

  • Find \(b_0\) and \(b_1\) that minimize the sum of squared differences between \(y_i\) and \(\hat{y}\)
  • In symbols:

\[(\hat{b}_0, \hat{b}_1)^\prime = \underset{b_{0},b_{1}}{\text{argmin}}\left[\sum_{i=1}^N(y_i - \hat{y}_i)^2\right] \\ = \underset{b_{0},b_{1}}{\text{argmin}}\left[\sum_{i=1}^N(y_i - b_0 - b_1x_i)^2\right]\]

OLS is the same loss function we use in ANOVA: minimize (sums of) squared errors between \(\hat{y}_i\)’s and the observed \(y_i\)’s

Standard Error of the Estimate

\[s_{y\cdot x} =\sqrt{\frac{\sum_{i=1}^N (y_i-\hat{y}_i)^2}{N-2}} = \sqrt{\frac{SS_{\text{residual}}}{df}}\]

  • \(s_{y \cdot x}\) is the standard deviation of \(y\) predicted from \(x\)
    • Notice the “\(\cdot\)” between \(y\) and \(x\)
  • \(s_{y \cdot x}^2\) is an unbiased estimator of \(\sigma_{y \cdot x}^2\)
  • \(s^2_{y\cdot x}\) is a measure of the accuracy of the regression line
  • \(s_{y\cdot x}\) is in the units of \(y\)

R-Squared

\(R^2 = r_{xy}^2\) is the effect size of the simple linear regression model

  • Proportion of the variance of \(y\) accounted for by \(x\)

Sample variation of \(\color{#FF7F00}{\underset{\text{\small sum of\\squares}}{{SS_y}}}\) = numerator of sample variance of y

\[SS_y = \sum_{i=1}^N(y_i - \bar{y})^2\]

\((y_i - \bar{y})\) can be decomposed into two parts:

\[ \color{#377EB8}{\underbrace{\color{black}{(y_i - \bar{y})}}_{\substack{\nearrow \\[0.2em] \text{\textbf{total}} \\ \text{variation of } y}}} = \color{#984EA3}{\underbrace{\color{black}{(y_i - \hat{y}_i)}}_{\substack{\uparrow \\[0.2em] \text{variation of } y \\ \text{\textbf{NOT} predicted by } x}}} + \color{#4DAF4A}{\underbrace{\color{black}{(\hat{y}_i - \bar{y})}}_{\substack{\nwarrow \\[0.2em] \text{variation of } y \\ \text{predicted by } x}}} \]

R-Squared

Sample variation of \(y\) (\(SS_y\)) can be decomposed into two parts:

\[SS_y = SS_{\text{residual}} + SS_{\text{regression}} \\ \sum(y_i - \bar{y})^2 = \sum(y_i - \hat{y}_i)^2 + \sum(\hat{y}_i - \bar{y})^2\]

  • \(SS_{\text{residual}}\): variation of the residuals
    • Like \(SS_{\text{within}}\) from ANOVA
  • \(SS_{\text{regression}}\): variation of \(y\) predicted by \(x\)
    • Like \(SS_{\text{between}}\) from ANOVA

\[R^2 = \frac{SS_{\text{regression}}}{SS_y} = 1 - \frac{SS_{\text{residual}}}{SS_y}\]

In the simple regression model, \(R^2 = r^2_{xy}\)

  • Proportion of variation in \(y\) accounted for by \(\hat{y}\)

R-Squared Viz 1

\(R^2\) represents how different the best fitting regression line is along the \(y\)-axis than the simple mean of \(y\)

R-Squared Viz 2

\(R^2\) represents how much smaller the residuals are for the regression line than for the simple mean of \(y\)

R-Squared Viz 3

  • \(R^2\) quantifies how much smaller the conditional SD of \(y\) given \(x\) is
    • \(s_y |x= \color{#984EA3} \sigma_{\epsilon} = 3.27\)

R-Squared Viz 3

  • Than the marginal SD of \(y\) ignoring \(x\) is
    • \(s_y = 5.36\)

Adjusted R-Squared

  • \(R^2\) is a positively biased estimate of the population squared correlation
  • Adjusted \(R^2\) is less biased, but not completely unbiased
  • For simple linear regression:

\[\text{Adjusted }R^2 = \left(R^2 - \frac{1}{N-1}\right)\left(\frac{N-1}{N-2}\right)\]

Standardized Regression

What happens if we standardize \(x\) and \(y\)?

What is standardization?

  • Converts a variable to \(Z\)-score units
  • \(Z_x = \frac{x -\bar{x}}{s_x}\)
  • \(Z_y = \frac{y -\bar{y}}{s_y}\)
  • New Intercept Interpretation: \(Z_y\) when \(Z_x = 0\) (Always 0)
  • New Slope Interpretation: Increase in \(Z_y\) for one unit increase in \(Z_x\) (\(r_{xy}\))

Map to Correlation

Standardized regression coefficients are those that describe the relationship between standardized variables

Standardized \(\hat{b}_0 = 0\) and \(\hat{b}_1 = r_{xy}\).

Unstandardized \(\hat{b}_1 = \frac{r_{xy}s_y}{s_x}\)

Unstandardized \(\hat{b}_0 = \bar{y} - \hat{b}_1\bar{x}\) (unstandardized \(\hat{b}_1\))

Test for Intercept

  • \(H_0: b_0 = 0\)
  • \(H_1: b_0 \neq 0\)
  • \(b_0\) is population regression intercept (sample statistic = \(\hat{b}_0\))

\[t_{\text{obs}}(df) = \frac{\hat{b}_0}{s_{\hat{b}_0}} \hspace{1cm} s_{\hat{b}_0}= \sqrt{\left(\frac{(1 - r^2_{xy})\times\sum(y_i - \bar{y})^2}{df}\right)\left(\frac{1}{N} + \frac{\bar{x}^2}{(N-1)\times s^2_{x}}\right)}\]

Intercept Test Terms

  • \(df\): degrees of freedom = \(N - 2\)
  • \(s_x^2\): sample variance of \(x\)
  • \(\bar{y}\): sample mean of \(y\)
  • \(\bar{x}\): sample mean of \(x\)
  • \(r_{xy}\): sample correlation between \(x\) and \(y\)

Under \(H_0\), \(t_{\text{obs}}(df)\) is \(t\)-distributed with \(df = N - 2\) degrees of freedom

Confidence interval:

\[\hat{b}_0 \pm t(df)_{\alpha/2} \times s_{\hat{b}_0}\]

Why Care?

What is the interpretation of the intercept?

  • Estimated mean of \(y\) when \(x = 0\)
  • Test is whether \(\bar{y}|(x=0) \neq 0\) when \(x = 0\)
  • Is 0 a plausible value for \(x\)?
  • Is 0 a plausible value for \(y\)?
  • Do you care specifically about \(\bar{y}|(x=0)\)?

Test for Slope

  • \(H_0: b_1 = 0\)
  • \(H_1: b_1 \neq 0\)
  • \(b_1\) is population regression slope of \(x\) on \(y\) (sample statistic = \(\hat{b}_1\))

\[t_{\text{obs}}(df) = \frac{\hat{b}_1}{s_{\hat{b}_1}}\]

\[s_{\hat{b}_1}= \frac{s_y}{s_x}\sqrt{\frac{1 - r^2_{xy}}{df}}\]

Slope Test Terms

  • \(df\): degrees of freedom = \(N - 2\)
  • \(s_y\): sample \(SD\) of \(y\)
  • \(s_x\): sample \(SD\) of \(x\)
  • \(r_{xy}\): sample correlation between \(x\) and \(y\)

Under \(H_0\), \(t_{\text{obs}}(df)\) is \(t\)-distributed with \(df = N - 2\) degrees of freedom

Confidence interval:

\[\hat{b}_1 \pm t(df)_{\alpha/2} \times s_{\hat{b}_1}\]

Hypothesis Tests for \(R^2\)

  • \(H_0\): population \(R^2 = 0\)
  • \(H_1\): population \(R^2 > 0\) (note: \(R^2\) cannot be negative)

\[F_{\text{obs}}(1, N-2) = \frac{MS_{\text{regression}}}{MS_{\text{residual}}}\]

  • \(MS_{\text{regression}} = \frac{SS_{\text{regression}}}{1}\) (\(MS\): “mean squares”)
  • \(MS_{\text{residual}} = \frac{SS_{\text{residual}}}{N-2}\)
  • \(N\): sample size

Under \(H_0\), \(F_{\text{obs}}\) follows the \(F\) distribution with 1 and \(N-2\) \(df\)

Test Equivalence

For simple regression (just one \(x\)), the following tests are all equivalent:

  • \(t\)-test of correlation \(r_{xy}\)
  • \(t\)-test of regression slope \(b_1\)
  • \(F\)-test of \(R^2\)

Why \(N-2\) \(df\)?

  • How many (which) parameters are we estimating in a simple regression?
    • One intercept and one slope. That’s why we “lose” 2 \(df\)

Assumptions

  1. All observations are conditionally independent
  • Nothing about one observation of \(x\) tells you anything about any other observation of \(x\) that \(y\) doesn’t already tell you (and vice versa)
  1. No outliers
  2. Across each predictor value, residuals are normally distributed with mean 0 and constant variance (homoscedasticity)
    • Equivalently put: There is a linear relationship between \(x\) and \(y\)
    • New version of the normality and homogeneity of variance assumptions

Residual Assumptions

  • For every point on the \(x\) axis
    • Residuals follow a normal distribution
    • Variance (SD) of \(y\) is constant

Non-Normal Residuals

Heteroscedasticity

Role of Assumptions

Models can be used for different purposes:

  • Describe
  • Predict
  • Decide

Our assumptions are primarily used to delineate the conditions under which hypothesis tests have known properties.

  • e.g., \(\alpha\) equals true Type I error rate

However they also can set the terms for which are descriptions can be correct and our predictions are likely to be accurate.

  • There are techniques to improve predictions under assumption violations (beyond this course)

Example

Original Study:

Pleskac, T. J. (2008). Decision making and learning while taking sequential risks. Journal of Experimental Psychology: Learning, Memory, and Cognition, 34, 167-185.

Replication study link: https://osf.io/3amj4

To what extent is the learning aspect of risk-taking behavior related to risky drug use?

ART = Angling Risk Tasks, computer game to study risk-taking behavior

Game play:

  • Subjects decide whether to cast a rod to catch fish in a pond
  • If red fish is caught, earn 5 cents and a chance to cast again
  • If blue fish is caught, end the round & lose money
  • Play 30 rounds per study condition
  • Subjects were compensated based on their winnings

Details

Conditions:

  • Weather:
    • Sunny day (S): subjects can see # of red & blue fish in the pond
    • Cloudy day (C): subjects cannot see # each type of fish
    • In cloudy day condition, subjects can learn about probabilities
  • Type of fishing:
    • Catch n’ release (R): probabilities of red and blue fish are constant
    • Catch n’ keep (K): probabilities change with successive casts

Each subject was exposed to 30 reps of all 4 combinations of conditions:

  • KS, KC, RS, RC

Variables:

  • Polydrug: count of the number of risky/illegal drugs ever tried (11 categories), weighted by frequency of use
  • ART scores (for each KS, KC, RS, RC): average number of casts taken on trials for which subjects chose to stop fishing (no blue fish)

More Details

Original comparisons of interest:

  • Are the correlations between ART scores and polydrug in the sunny conditions greater than the correlations for the cloudy conditions?

Let’s test a simpler hypothesis:

  • Are KC scores related to real-life risk-taking behavior (polydrug)?
    • Catch n’ keep on a cloudy day

Assumption Checks

Assumptions are typically check graphically

  • Normality: QQ Plot of residuals
  • homoscedasticity:
    • Plot \(x\) variable along \(x\)-axis
    • Plot residuals along \(y\)-axis
    • Spread of residuals (vertically) should be uniform for different values of \(x\) variable (horizontal)

QQ Residuals

First we use residuals() function to extract residuals

dat$residuals <- residuals(lm1)

Then we can create a QQ plot like we’ve learned

ggplot(dat, aes(sample = residuals)) + stat_qq() + stat_qq_line(col = my_red) +
  theme_light()

QQ Plot

Homoscedasticity

For homoscedasticity, I will

  • Plot \(x\)-values along \(x\)-axis
  • Residuals along \(y\)-axis
  • Add horizontal reference line at \(y = 0\)
  • Points should be uniformly and noisily spread around reference line
ggplot(dat, aes(KC, residuals)) +
  geom_hline(yintercept = 0, col = my_blue) +
  geom_point() + theme_light()

Homoscedasticity Plot

Interpretations

  • Normality seems somewhat violated
    • Tails of QQ Plot deviate from reference line
    • If \(N\) is large enough, relatively robust to violations of normality due to central limit theorem
  • Homoscedasticity seems somewhat violated (aka relationship is heteroscedastic)
    • Variance seems a bit larger for small values of KC than large values of KC
    • Heteroscedasticity can bias standard errors of regression coefficients (more on this in multiple regression lectures)

Bayesian Version

We can do simple regression in rstanarm exactly as we have seen every other time we have estimated a linear model (it’s more what rstanarm was built to do!)

  • Stronger priors might cause posterior means to differ

Bayesian \(R^2\) Review

Because Bayesian estimates aren’t deterministic the way the simple OLS algorithm is, the traditional \(R^2\) is not guaranteed to be \(0 \leq R^2 \leq 1\)

  • Means it is possible for the model to explain more than the total variance
    • Not a sensible interpretation!

Alternative:

\[\text{Bayesian } R^2 = \frac{s_{\hat{y}}^2}{s_{\hat{y}}^2 + s_{\epsilon}^2}\]

  • Is guaranteed to be \(0 \leq \text{Bayesian } R^2 \leq 1\)
  • Same interpretation as \(\eta^2\) and \(R^2\)
