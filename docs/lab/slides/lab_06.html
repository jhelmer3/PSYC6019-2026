Effect Size

Effect Size

Effect sizes provide ways to estimate the magnitude of an effect

○ Standardized, so we can compare differences across scales

Cohen’s \(d\): measure of difference (not a test)

○ Transforms to the z-scale, can interpret in standard deviation units

○ Mathematically, looks like t-statistic equations but has standard deviation (\(s\)) in the denominator instead of standard error (\(SE\)).

Cohen’s d

One Sample

\[ d = \frac{\bar{x} - \mu_0}{s_x} \]

mu_cty <- 30

cty_bar <- mean(mpg$cty)
cty_sd <- sd(mpg$cty)

(cty_bar - mu_cty) / cty_sd
[1] -3.087686

Independent Samples

\[ d = \frac{\bar{x}_1 - \bar{x}_2}{s_p} \]

  • Pull Data
  • Calculate \(d\)
four_cyl <- mpg |>
  filter(cyl == 4) |>
  pull(hwy)
eight_cyl <- mpg |>
  filter(cyl == 8) |>
  pull(hwy)
x_bar_four <- mean(four_cyl)
sd_four <- sd(four_cyl)
n_four <- length(four_cyl)
x_bar_eight <- mean(eight_cyl)
sd_eight <- sd(eight_cyl)
n_eight <- length(eight_cyl)

pooled_sd <- sqrt( 
  ((n_four - 1) * sd_four^2 + 
     (n_eight - 1) * sd_eight^2) /
    ((n_four - 1) + (n_eight - 1)) 
)
(x_bar_four - x_bar_eight) / pooled_sd
[1] 2.804565

Risk and Odds

Biologists have studied which kinds of food helps chicks grow best. They randomly assigned newly hatched chicks into different feed type groups and measured their body weight in grams after six weeks. This is a subset of the data that labels chicks under 250g small chicks and chicks above 250g large chicks.

Feed Small Large Total
linseed 8 4 12
soybean 9 5 14
sunflower 1 11 12
Total 18 20 38

What is the risk of a chick being small if they were in the linseed group? Soybean?

\(\text{Risk(small | linseed)} = \frac{8}{12} = 0.6\bar{6}\)

\(\text{Risk(small | soybean)} = \frac{9}{14} = 0.64\)

What are the odds of a chick being small if they were in the linseed group? Sunflower?

\(\text{Odds(small | linseed)} = \frac{8}{4} = 2\)

\(\text{Odds(small | sunflower)} = \frac{1}{11} = 0.\bar{09}\)

What is the risk ratio of a chick being small if they were in the linseed group compared to the soybean?

\(\text{Risk ratio} = \frac{\text{Risk(small | linseed)}}{\text{Risk(small | soybean)}} = \frac{\frac{8}{12}}{\frac{9}{14}} = 1.03\)

What is the odds ratio of a chick being small if they were in the linseed group compared to the sunflower?

\(\text{Odds ratio} = \frac{\text{Odds(small | linseed)}}{\text{Odds(small | sunflower)}} = \frac{\frac{8}{4}}{\frac{1}{11}} = 22\)

The odds of a chick being small is 22x greater if they are fed linseed compared to if they are fed sunflowers!

Power Analysis

Power Analysis

Power: the proportion of times we’d correctly reject the null hypothesis \(H_0\) when something else is true, over many hypothetical repeated experiments

Power analysis: the chance of correctly rejecting \(H_0\) if \(H_0\) is not the reality.

○ Given that our null hypothesis is \(H_0: \mu = \mu_0\),

○ How often would we correctly reject the null if \(\mu\) was not \(\mu_0\)?

\(\beta\): probability of incorrectly retaining the null when \(H_0\) is false

\(1 - \beta\): power (probability of correctly rejecting the null when \(H_0\) is false)

What can we change in power analysis?

Power Analysis

We can use the pwr package in R to conduct power analyses! For a t-test,

pwr.t.test(n, d, sig.level, power)

○ n = sample size in each group
○ d = true effect size
○ sig.level = significance level, \(\alpha\)
○ power = power, \(1 - \beta\)

Specify exactly three of the four, it will fill in the fourth

○ alternative = type of test, default is "two.sided"

Aside: Low-Powered Studies

One of the components of the replication crisis is low-powered studies combined with publication bias (studies with \(p < .05\) tend to get published more than \(p \geq .05\)). Why?

When studies have small sample sizes (and thus low power), their standard errors are large, because \(SE = \frac{s_x}{\sqrt{N}}\).

When standard errors are large, it takes a very large effect size to “beat” the null. So, low-powered studies that do beat the null are going to report a larger effect size.

But when they’re the only studies that get published (selection on significance), it looks like some effect is large in the literature, when in fact the rest of the distribution of effect sizes are left in the file drawer.

Low-powered studies will often yield null results, but when they do have a significant effect (by chance), the effect will appear large.

(Ioannis 2005, “Why Most Published Research Findings Are False”), (Gelman 2006, “What ‘Power = .06’ Looks Like”)

Power Analysis

Can create power curves by iterating over candidate values for one of the inputs and calculating the remaining.

Example: You are running a study that you believe has a true effect size of \(\delta = 0.25\). You want to test your hypothesis with a t-test at \(\alpha = .05\). What will your power be at varying levels of sample size \(N\) per group?

sample_sizes <- c(10, 30, 100, 300)
power_values <- map_dbl(
  sample_sizes, 
  function(sample_size) {
    pwr::pwr.t.test(
      n = sample_size, 
      d = 0.25, 
      sig.level = 0.05)$power
  }
)

map_dbl(): iterate over every item in sample_sizes, do something to it, and return a double (number with decimal points).

function(sample_size): defines a function, tells map_dbl() what we want to do to each sample_size.

pwr::pwr.t.test(...)$power: the same function we were using before.
