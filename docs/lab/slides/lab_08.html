Analysis of Variance (ANOVA)

Analysis of Variance (ANOVA)

Method of understanding how categorical variables are related to a continuous outcome of interest

Compares between groups to within groups variance to jointly compare multiple means

ANOVA: Partitioning Variance

Total Sum of Squared Errors: error term around the grand mean

\[ SS_{total} = \sum (x_i - \bar{x})^2 \]

If we have outcomes separated into different groups (e.g., control, treatment A, treatment B), can partition \(SS_{total}\) into between groups sums of squares \(SS_B\) and within groups sums of squares \(SS_W\)

\[ SS_{total} = SS_B + SS_W \]

So, with \(j\) indexing \(J\) total groups and \(i\) indexing \(I\) people within a group, we can write \(SS_{total}\) as…

ANOVA: Partitioning Variance

Total Sum of Squared Errors: error term around the grand mean

\[ SS_{total} = \sum_{j=1}^J \sum_{i=1}^I (x_{ij} - \bar{x})^2 \]

Between-Group Sum of Squares: error between the group mean and the grand mean

\[ SS_{B} = \sum_{j=1}^J n_j (\bar{x_{j}} - \bar{x})^2 \]

Within-Group Sum of Squares: error between observations and their group mean

\[ SS_{W} = \sum_{j=1}^J \sum_{i=1}^I (x_{ij} - \bar{x_{j}})^2 \]

ANOVA: \(F\)

Mean Square Between

\(MS_B = \frac{SS_B}{J - 1} = \frac{\sum_{j=1}^J n_j (\bar{x_{j}} - \bar{x})^2}{J - 1}\)

Mean Square Within

\(MS_W = \frac{SS_W}{N - J} = \frac{\sum_{j=1}^J \sum_{i=1}^I (x_{ij} - \bar{x})^2}{N - J}\)


\[ F = \frac{MS_B}{MS_W} \]

ANOVA: Hypotheses

\(H_0\): \(\mu_1 = \mu_2 = ... = \mu_J\)

\(H_1\): not \(H_0\)

Equivalent to:

\(H_0\): \(\sigma^2_B = 0\)

\(H_1\): \(\sigma^2_B \neq 0\)

Missing Some Penguins (Data)!

The penguins dataset has missing data, as do many real-life datasets. R represents these as NAs.

This is something to definitively be aware of. While many functions will handle missing data in some way for you, which can be convenient, they often do so silently (without saying anything!).

Some functions will simply return NA, and these often have an na.rm (remove NAs) argument. For example,

mean(penguins$flipper_length_mm)

Frequentist ANOVA

ANOVA: R function

aov(y ~ grouping_var, data = data)

○ y = outcome

○ grouping_var = name of grouping variable

○ data = dataframe that includes grouping_var and y

Very similar syntax to lm(y ~ predictor, data = data)

Uses dummy coding by default

summary(model) prints out results

ANOVA as a Linear Model

ANOVA as a Linear Model

Like t-tests, ANOVAs are just another phrasing of a linear model.

Now, we have a slope term for each of our groups minus one (\(J - 1\) for \(J\) groups)

○ Depending on the variable coding, the parameters present the information differently.

○ But ultimately, conducting an ANOVA explicitly as a linear model provides all the same information as conducting it in the sums of squares framework.

We are still interested in differences between means of groups, we just have more groups now (compared to t-test).

Let’s consider an example of an experiment where we have three groups: a control group, a treatment A group, and a treatment B group.

ANOVA as a Linear Model

With dummy coding, we use one group as a reference group and compare all others to it by using indicator variables representing belonging in each other group.

\[y = \beta_0 + \beta_A \text{trt}_A + \beta_B \text{trt}_B + \epsilon\]

where \(\text{trt}_A = 1\) if the participant was in treatment A and is \(0\) otherwise (and similarly for \(\text{trt}_B\))

Slope Interpretations

○ \(\beta_0 =\) mean of control group

○ \(\beta_A =\) difference in means between control group and treatment A group

○ \(\beta_B =\) difference in means between control group and treatment B group

Accessing Group Means

○ \(\beta_0 =\) mean of control group

○ \(\beta_0 + \beta_A =\) mean of treatment A group

○ \(\beta_0 + \beta_B =\) mean of treatment B group

With dummy coding, we use one group as a reference group and compare all others to it by using indicator variables representing belonging in each other group.

\[y = \beta_0 + \beta_A \text{trt}_A + \beta_B \text{trt}_B + \epsilon\]

where \(\text{trt}_A = 1\) if the participant was in treatment A and is \(0\) otherwise (and similarly for \(\text{trt}_B\))

ANOVA as a Linear Model

With effect coding, we let the grand mean be the “reference” point and examine \(J - 1\) groups as by their deviation from the grand mean.

\[y = \beta_0 + \beta_A x_A + \beta_B x_B + \epsilon\]

where \(x_A = 1\) if the participant was in treatment A, \(x_A = -1\) if the participant was in the control, and is \(0\) otherwise. Similarly, \(x_B = 1\) if the participant was in treatment B, \(x_B = -1\) if the participant was in the control, and is \(0\) otherwise.

Slope Interpretations

○ \(\beta_0 =\) overall grand mean

○ \(\beta_A =\) deviation of treatment A from grand mean

○ \(\beta_B =\) deviation of treatment B from grand mean

Accessing Group Means

○ \(\beta_0 =\) overall grand mean

○ \(\beta_0 + \beta_A =\) mean of treatment A group

○ \(\beta_0 + \beta_B =\) mean of treatment B group

○ \(\beta_0 + (-1)\beta_A + (-1)\beta_B =\) mean of control group

ANOVA as a Linear Model

With effect coding, we let the grand mean be the “reference” point and examine \(J - 2\) groups by their deviation from the grand mean.

\[y = \beta_0 + \beta_A x_A + \beta_B x_B + \epsilon\]

where \(x_A = 1\) if the participant was in treatment A, \(x_A = -1\) if the participant was in the control, and is \(0\) otherwise. Similarly, \(x_B = 1\) if the participant was in treatment B, \(x_B = -1\) if the participant was in the control, and is \(0\) otherwise.

Changing to Effect Coding

We can tell R we want to use effect coding instead of dummy coding; we don’t have to manually create the effect coding columns ourselves.

We need to set the contrasts setting of our grouping variable to contr.sum. Everything you run after that will use effect coding.

Before (default)

contrasts(penguins_cleaned$species)
          Chinstrap Gentoo
Adelie            0      0
Chinstrap         1      0
Gentoo            0      1

After

contrasts(penguins_cleaned$species) <- contr.sum
contrasts(penguins_cleaned$species)
          [,1] [,2]
Adelie       1    0
Chinstrap    0    1
Gentoo      -1   -1
flipper_model_lm_effect <- lm(flipper_length_mm ~ species, data = penguins_cleaned)

What two effects will we see in the slope parameters? Adelie and Chinstrap!

Changing to Effect Coding

By default, R switches the last level to be the one omitted from the slope paramters. To change, reorder the levels.

penguins_cleaned$species_reordered <- factor(penguins_cleaned$species, levels = c("Chinstrap", "Gentoo", "Adelie"))
contrasts(penguins_cleaned$species_reordered) <- contr.sum
contrasts(penguins_cleaned$species_reordered)
          [,1] [,2]
Chinstrap    1    0
Gentoo       0    1
Adelie      -1   -1

Changing to Dummy Coding

Dummy coding is the default, but if you change it to effect coding and need to change it back to dummy coding, set it to contr.treatment.

contrasts(penguins_cleaned$species) <- contr.treatment # back to dummy coding
contrasts(penguins_cleaned$species)
