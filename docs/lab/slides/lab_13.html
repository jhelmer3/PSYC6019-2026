Multiple Regression

Multiple Regression

So far, we’ve only examined the relationship between a continuous outcome and continuous predictor one at a time with simple regression. With multiple regression, we can examine these relationships jointly: looking at one relationship while adjusting for the relationships of other variables.

\[y_i = \beta_0 \, + \, \beta_1 x_{1i} \, + \, \beta_2 x_{2i} \, + \, ... \, + \, \beta_p x_{2i} \, + \, \epsilon\]

○ \(\beta_0\): value of \(y\) when all predictors \(x = 0\)

○ \(\beta_1\): slope of \(x_{1i}\) adjusted for the effect of \(x_{2i}, \, ..., \,x_{pi}\)

Regression Diagnostics

With multiple regression, we want to check on…

  • Normality of residuals

    • Relationships with other variables

  • Multicollinearity among predictors

  • Outliers

Normality of Residuals

Multicollinearity

Multicollinearity

Multicollinearity refers to the ability of predictors to be associated with each other.

High multicollinearity: when the predictors in the model can explain a high amount of variance in another predictor.

Squared Multiple Correlations

For each predictor, we need to examine the total amount of variance that the remaining predictors can explain of it.

\[\text{body mass} = \beta_0 + \beta_1\text{bill length} + \beta_2\text{bill depth} + \beta_3\text{flipper length} + \epsilon\]

In the models

\(\text{bill length} = \beta_0 + \beta_1\text{bill depth} + \beta_2\text{flipper length} + \epsilon\)

\(\text{bill depth} = \beta_0 + \beta_1\text{bill length} + \beta_2\text{flipper length} + \epsilon\)

\(\text{flipper length} = \beta_0 + \beta_1\text{bill depth} + \beta_2\text{bill length} + \epsilon\)

what is the amount of variance the predictors (i.e., the other predictors in the model of interest)?

We can assess the amount of variance predictors can account for in an outcome with \(R^2\).

Squared Multiple Correlations

The \(R^2\) of these models (again, predictors in the model of interest trying to predict each other) is called squared multiple correlations, \(SMC\)s.

\(\text{bill length} = \beta_0 + \beta_1\text{bill depth} + \beta_2\text{flipper length} + \epsilon\)

\(\text{bill depth} = \beta_0 + \beta_1\text{bill length} + \beta_2\text{flipper length} + \epsilon\)

\(\text{flipper length} = \beta_0 + \beta_1\text{bill depth} + \beta_2\text{bill length} + \epsilon\)

Squared Multiple Correlations

multicoll_m1 <- lm(bill_length_mm ~ bill_depth_mm + flipper_length_mm, data = penguins)
summary(multicoll_m1)$r.squared
[1] 0.4638329

summary(multicoll_m2)$r.squared
[1] 0.3793799
multicoll_m3 <- lm(flipper_length_mm ~ bill_depth_mm + bill_length_mm, data = penguins)

[1] 0.6259358

Variance Inflation Factor

The presence of multicollinearity among predictors in the model increases the variance of the model estimates. We can examine this effect with Variance Inflation Factors (\(VIF\)s).

\[VIF_p = \frac{1}{1 - SMC_p}\]

car::vif(m3)
   bill_length_mm     bill_depth_mm flipper_length_mm 
         1.865090          1.611292          2.673338

VIF suggested cutoffs

Tolerance

An alternative way of looking at this is with tolerance, which is just the inverse of \(VIF\).

\[tolerance = \frac{1}{VIF}\]
