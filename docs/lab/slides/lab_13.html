Multiple Regression

Multiple Regression

So far, we’ve only examined the relationship between a continuous outcome and continuous predictor one at a time with simple regression. With multiple regression, we can examine these relationships jointly: looking at one relationship while adjusting for the relationships of other variables.

\[y_i = \beta_0 \, + \, \beta_1 x_{1i} \, + \, \beta_2 x_{2i} \, + \, ... \, + \, \beta_p x_{2i} \, + \, \epsilon\]

○ \(\beta_0\): value of \(y\) when all predictors \(x = 0\)

○ \(\beta_1\): slope of \(x_{1i}\) adjusted for the effect of \(x_{2i}, \, ..., \,x_{pi}\)

Confounders

One assumption of linear regression is that our model is correctly specifed.

These results are an example of omitted variable bias. The relationship between bill depth and body mass looks negative, but we see clusters of positive-looking relationships.

Since we have worked with this data so much, we know what the omitted variable likely influencing this clustering is: species!

Species as an omitted variable is currently confounding the relationship between bill depth and body mass.

  • Plot
  • Code
ggeffects::ggpredict(m1, terms = c("bill_depth_mm_z")) |>
  plot() +
  geom_point(
    data = penguins_cleaned,
    aes(x = bill_depth_mm_z, y = body_mass_g)
  )

We can account for species by including it as a predictor in our model, going from single to multiple regression!

Note that we may not have noticed this had we not looked at the predictions against the data.

Regression Diagnostics

With multiple regression, we want to check on…

  • Normality of residuals

    • Relationships with other variables

  • Multicollinearity among predictors

  • Outliers

If you had a model with only continuous predictors, you could pivot_longer() the columns with the predictor values (names(coef(lm_model))) so each predictor has a row: then you can just facet_wrap() by the predictor name!

  • Plot
  • Code
m_numeric_only <- lm(body_mass_g ~ bill_length_mm_z + 
                       bill_depth_mm_z + flipper_length_mm_z, 
                     data = penguins_cleaned)

penguins_cleaned |>
  mutate(residuals = residuals(m_numeric_only)) |>
  pivot_longer(any_of(names(coef(m_numeric_only))),
               names_to = "predictor", values_to = "x") |>
  ggplot(aes(x = x, y = residuals)) +
  geom_point() +

Squared Multiple Correlations

For each predictor, we need to examine the total amount of variance that the remaining predictors can explain of it.

\[\text{body mass} = \beta_0 + \beta_1\text{bill length} + \beta_2\text{bill depth} + \beta_3\text{flipper length} + \epsilon\]

In the models

○ \(\text{bill length} = \beta_0 + \beta_1\text{bill depth} + \beta_2\text{flipper length} + \epsilon\)

○ \(\text{bill depth} = \beta_0 + \beta_1\text{bill length} + \beta_2\text{flipper length} + \epsilon\)

○ \(\text{flipper length} = \beta_0 + \beta_1\text{bill depth} + \beta_2\text{bill length} + \epsilon\)

what is the amount of variance the predictors (i.e., the other predictors in the model of interest)?

We can assess the amount of variance predictors can account for in an outcome with \(R^2\).

Squared Multiple Correlations

The \(R^2\) of these models (again, predictors in the model of interest trying to predict each other) is called squared multiple correlations, \(\mathrm{SMC}\)s.

○ \(\text{bill length} = \beta_0 + \beta_1\text{bill depth} + \beta_2\text{flipper length} + \epsilon\)

○ \(\text{bill depth} = \beta_0 + \beta_1\text{bill length} + \beta_2\text{flipper length} + \epsilon\)

○ \(\text{flipper length} = \beta_0 + \beta_1\text{bill depth} + \beta_2\text{bill length} + \epsilon\)

Variance Inflation Factor

The presence of multicollinearity among predictors in the model increases the variance of the model estimates. We can examine this effect with Variance Inflation Factors (\(\mathrm{VIF}\)s).

\[\mathrm{VIF}_\mathrm{p} = \frac{1}{1 - \mathrm{SMC}_\mathrm{p}}\]

where \(p\) is a given model predictor.

Our numeric-predictors-only penguin model:

car::vif(m_numeric_only)
   bill_length_mm_z     bill_depth_mm_z flipper_length_mm_z 
           1.865090            1.611292            2.673338

Variance Inflation Factors indicate the factor by which the standard error has increased because of multicollinearity for that predictor.

Tolerance

An alternative way of looking at this is with tolerance, which is just the inverse of \(VIF\).

\[\mathrm{tolerance}_\mathrm{p} = \frac{1}{\mathrm{VIF}_\mathrm{p}} = 1 - \mathrm{SMC}_\mathrm{p}\]

Our numeric-predictors-only penguin model:

1 / car::vif(m_numeric_only)
   bill_length_mm_z     bill_depth_mm_z flipper_length_mm_z 
          0.5361671           0.6206201           0.3740642

Tolerance indicates the proportion of variance in a given predictor that is independent of other predictors.

Outliers

Outliers

Outliers are datapoints that fall far away from the rest of the datapoints.

○ Might be an unusual predictor value (or unusual combination of predictor values)

○ Might be an unusual outcome value given the predictor values

We can describe all datapoints based on their leverage, distance, and influence.

○ High values on these characteristics may indicate a datapoint is an outlier.

Outlier Detection

Leverage

Leverage represents the distance of a set of predictor values to the centroid of the predictor density

○ Potential to affect regression results

\(h\), or “hat,” values indicate how far a point is from the centroid

Distance

Distance values are unusual outcome values given the observations’ predictors

○ Based on an observation’s residual

Studentized residuals provide a measure of distance

Influence

Influence indicates the amount an observation actually changes the results of a regression.

Function of leverage and distance

Considers the difference in predictions if a datapoint were removed

Leverage and distance represent a potential to influence results, but don’t necessarily mean the results were affected.

Influence does represent the degree of change in the model!

Influence

Influence indicates the amount an observation actually changes the results of a regression.

DFFITS

\[ \mathrm{DFFITS} = \frac{\hat{y} - \hat{y}_{(i)}}{s_{\hat{y}_{(i)}}} \]

○ \(\hat{y}\): predicted value of \(y_i\) when \(i\) is included in the regression

○ \(\hat{y}_{(i)}\): predicted value of \(y_i\) when \(i\) is NOT included in the regression

○ \(s_{\hat{y}_{(i)}}\): standard error of \(\hat{y}_{(i)}\)

How much would the regression line change if \(i\) was not in the dataset?

DFBETAS

Similar to DFFITS, but examines change in estimated regression coefficients.

\[ \mathrm{DFBETAS} = \frac{\hat{b} - \hat{b}_{(i)}}{s_{\hat{b}_{(i)}}} \]

○ \(\hat{b}\): predicted value of \(b_i\) when \(i\) is included in the regression

○ \(\hat{b}_{(i)}\): predicted value of \(b_i\) when \(i\) is NOT included in the regression

○ \(s_{\hat{b}_{(i)}}\): standard error of \(\hat{b}_{(i)}\)

How much would the regression coefficients change if \(i\) was not in the dataset?

Matrix Math in R

Matrix Math in R

While most of the time, R functions will do the work of handling matrix math for us, it can be handy to know a few functions and operations to do matrix math yourself.

The matrix() function allows us to create matrices. We can also convert from a dataframe with as.matrix().

matrix(data, nrow = 1, col = 1, byrow = FALSE)

By default, matrix() will input values down columns first. Change byrow = TRUE to swap to by rows first.

c(1, 2, 3, 4) |>
  matrix()
     [,1]
[1,]    1
[2,]    2
[3,]    3
[4,]    4
c(1, 2, 3, 4) |>
  matrix(nrow = 2)
     [,1] [,2]
[1,]    1    3
[2,]    2    4
c(1, 2, 3, 4) |>
  matrix(nrow = 2, byrow = TRUE)
     [,1] [,2]
[1,]    1    2
[2,]    3    4
M <- tibble(
  x1 = c(1, 2, 3),
  x2 = c(4, 5, 6),
  x3 = c(7, 8, 9)
) |>
  as.matrix()
M
     x1 x2 x3
[1,]  1  4  7
[2,]  2  5  8
[3,]  3  6  9

Transposing a Matrix

Transposition (denoted \(\bf{M}^\top\) or \(\bf{M}'\), read “M transposed” or “M prime”) flips the matrix columns and rows. The t(matrix) function will transpose matrices.

M
     x1 x2 x3
[1,]  1  4  7
[2,]  2  5  8
[3,]  3  6  9
t(M)
   [,1] [,2] [,3]
x1    1    2    3
x2    4    5    6
x3    7    8    9

Matrix Multiplication

By default, using the * operator in R multiplies elements from each cell of a matrix.

M * M
     x1 x2 x3
[1,]  1 16 49
[2,]  4 25 64
[3,]  9 36 81

To apply real matrix multiplication, use the %*% operator.

M %*% M
     x1 x2  x3
[1,] 30 66 102
[2,] 36 81 126
[3,] 42 96 150

For vectors (single column matrices), this will compute the dot product and result in a scalar (one number).

c(1, 2, 3) %*% c(1, 2, 3)
     [,1]
[1,]   14

Inverting a Matrix

A matrix multiplied by its inverse equals the identity matrices. In that way, it is similar to the reciprocal value for scalars.

Scalars

\[ x \times \frac{1}{x} = 1 \]

Matrices

\[ \bf{M} \times \bf{M}^{-1} = \bf{I} \]

To invert a matrix in R, use the solve() function.

(M <- tibble(
  x1 = c(1, 0, 3),
  x2 = c(2, 3, 0),
  x3 = c(0, 4, 5)
) |>
  as.matrix())
     x1 x2 x3
[1,]  1  2  0
[2,]  0  3  4
[3,]  3  0  5
solve(M)
