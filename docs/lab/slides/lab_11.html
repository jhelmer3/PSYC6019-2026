Repeated Measures ANOVA

Repeated Measures ANOVA

It is sometimes the case that we have repeated measures data

○ Responses collected on the same measure for the same subjects more than one time

Some examples of repeated measures data are…

○ A mental health screening questionnaire given to participants once per day

○ A yearly customer satisfaction survey

For these designs, we have to consider if conditions are between-person or within-person.

Aside: across()

across() is a helpful tidyverse function that can be used within functions like summarize() and mutate().

When we want to apply the same transformation to multiple columns, we can target them all with across() and specify the transformation once, instead of manually specifying each one.

across(columns, function(s))

○ columns = <tidy-select> columns to target

○ function(s) = name of function to use, anonymous function, or list of functions.

Repeated Measures Example

ez::ezANOVA(data, dv, wid, within = NULL, between = NULL, type = 2)

○ dv = the outcome variable

○ wid = name of the column with subject identifier. Typically contains an id for each person (here, each chick!)

○ within = column(s) with within-subject factors

○ between = column(s) with between-subject factors

○ type = the sums of squares method used

= NULL means the default is set to NULL, and you do not necessarily need to input a value for that argument for the function to work. (May need to specify it for the function to work the way you want, though! Depends on your ANOVA goal.)

afex ANOVAs

Unfortunately, the ez package is not being maintained very much right now, so it is less equipped to integrate with other tools like emmeans. Another package with ANOVA functionality, afex, is! It has many ways of specifying the form of the ANOVA you want to estimate, including one very similar to the ezANOVA() syntax.

afex::aov_ez(id, dv, data, between = NULL, within = NULL, type = 3)

○ id = character vector name of the column with subject identifier

○ dv = character vector the outcome variable

○ within = character vector column(s) with within-subject factors

○ between = character vector column(s) with between-subject factors

○ type = the sums of squares method used

Note that afex::aov_ez() uses Type III sums of squares by default.

Multilevel Modeling

Multilevel Modeling

Multilevel Modeling (MLM) is a more flexible framework for examining between- and within-subject variation!

ANOVA can’t handle missing cells (e.g., if we were missing weight observations for diet 3 in week 4), but MLM can! It can also handle uneven spaces between time intervals (e.g., if we had observations on day 1, day 5, day 6, day 8, and day 30).
