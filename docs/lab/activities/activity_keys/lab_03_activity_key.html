Replace existing distributions with \(chi^2\) distributions of varying degrees of freedom, specifically df = 1, 2, 3, and 4.

5) Make your modifications to the simulation and show the results! Please include results for both the sample and sampling distributions.

n_reps <- 1000
sample_size <- c(3, 10, 30, 100)
total_n <- sum(n_reps * sample_size)

sim_data <- tibble(
  n_reps = n_reps,
  sample_size = sample_size
) |>
  uncount(n_reps, .id = "rep") |>
  uncount(sample_size, .id = "index", .remove = F) |>
  mutate(
    draw_chisq_1 = rchisq(total_n, df = 1),
    draw_chisq_2 = rchisq(total_n, df = 2),
    draw_chisq_3 = rchisq(total_n, df = 3),
    draw_chisq_4 = rchisq(total_n, df = 4)
  ) |>
  pivot_longer(starts_with("draw"),
               names_to = "distribution", values_to = "draw")

means <- sim_data |>
  summarize(.by = c(rep, distribution, sample_size),
            sample_mean = mean(draw))

sim_data |>
  filter(rep %in% sample(n_reps, size = 30)) |>
  ggplot(aes(x = draw, y = distribution,
             color = distribution, group = interaction(distribution, rep))) +

  theme_classic(base_size = 14) +

4a) Is the billboards dataset in wide or long format? How can you tell?

Wide! An “observation” here is a ranking in a given week, but all the weeks are in columns. They don’t have to specifically mention that an observation is a ranking in a week, but just something like this.
