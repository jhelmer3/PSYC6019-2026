5) Come up with one question you’d like to ask of the data through data visualization (this can be the same, similar, or different from your question in (3)), and write the question below.

Is there a relationship between the number of yellow and red cards a team gets?

6) Start by creating just the bare bones of the plot. Use the ggplot() function and set the data and mapping argument. For the mapping argument, think carefully about which variables you want to set on which axes using the aes() function.

player_stats |>
  summarize(.by = team_name,
            total_yellow_cards = sum(yellow_cards),
            total_red_cards = sum(red_cards)) |>
  ggplot(mapping = aes(x = total_yellow_cards, y = total_red_cards))

7) Next, add a geom_ layer.

player_stats |>
  summarize(.by = team_name,
            total_yellow_cards = sum(yellow_cards),
            total_red_cards = sum(red_cards)) |>
  ggplot(mapping = aes(x = total_yellow_cards, y = total_red_cards)) +
  geom_jitter(height = .1, width = .1)
