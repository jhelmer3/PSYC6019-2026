Activity

1) Load in the tidyverse packages with library(tidyverse). Then, read in the world_cup_player_stats.csv data and assign it to a variable.

2) Use at least two functions to explore and ‘get a sense of’ the data (HINT: glimpse() can be one of them).

3) Come up with one question you’d like to ask of the data through data transformation (feel free to use the ones from the slides as inspiration, but it shouldn’t be the exact same), and write the question below.

4) Use a tidyverse pipe chain to address this question.

5) Come up with one question you’d like to ask of the data through data visualization (this can be the same, similar, or different from your question in (3)), and write the question below.

6) Start by creating just the bare bones of the plot. Use the ggplot() function and set the data and mapping argument. For the mapping argument, think carefully about which variables you want to set on which axes using the aes() function.

7) Next, add a geom_ layer.

8) Briefly interpret this plot (1–2 sentences).

9) Make at least one structural modification to this plot. By structural modification, I mean changing either (1) something in the data being plotted, (2) something in the data mapping in the aes() argument, or (3) the geom(s) being plotted.

10) Briefly interpret this new plot (1–2 sentences).

11) Finally, make at least three additional modifications to this plot. This can include changes to the theme, scales, labels, etc. Please provide a brief justification for each change (e.g., making the plot visually cleaner, clarifying expected breaks in scale, adding text to explain the plot).
